# Release Notes – PlantBot Bewässerung **1.2.10-gamma**

**Datum:** 2026-08-29  
**Basis:** Änderungen seit **v1.2.10-alpha** / MQTT-Live-Daten-Stand auf `main`.  
**Voraussetzung:** Plantbot-Firmware **≥ 1.3.0-gamma** (MQTT-Status mit `latest_version` / `update_needed`).  
**Firmware:** [PlantBot Firmware v1.3.0-gamma](https://github.com/fabibo89/plantbot-OTA/releases/tag/v1.3.0-gamma)  
**Hinweis:** Pre-release – mit Firmware ≥ 1.3.0-gamma testen.

## Zugehörige Firmware (v1.3.0-gamma)

→ **[plantbot-OTA Release v1.3.0-gamma](https://github.com/fabibo89/plantbot-OTA/releases/tag/v1.3.0-gamma)**

Delta seit Firmware-Beta: Update-Erkennung über MQTT-Status (`latest_version`, `update_needed`), periodischer Check alle 6 h Idle.

## Features

- **Firmware-Update-Info per MQTT:** Coordinator übernimmt `latest_version` und `update_needed` aus `plantbot/{ip}/status`. Die Update-Entity zeigt verfügbare Updates, ohne HTTP-`/status` zu pollen.
- Sensor **„Update erforderlich“** wird immer angelegt (Wert kommt sobald Status-MQTT eintrifft).

## Bereits auf main (Voraussetzung / Kontext)

Falls noch nicht im Einsatz — seit 1.2.10-alpha / neueren Commits u. a.:

- Live-Daten per MQTT (`sensors` / `status` / `valves`), Availability-Heartbeat
- Flow, Volume, Wasser Runtime, Letzter Reset Grund aus MQTT-Status
- Event **`plantbot_watering_finished`** (Server-Betrieb) inkl. `plant_name`
- Server-Refresh behält MQTT-Livedaten; Sensor-Fallback über Server `last_value`

## Breaking / Voraussetzung

- **Benötigt Firmware ≥ 1.3.0-gamma** für zuverlässige Update-Anzeige in HA.
- Ältere Firmware (Alpha/Beta) liefert ggf. noch keine `latest_version`/`update_needed` im Status → Update-Entity bleibt ohne „Update verfügbar“, obwohl die Station beim Boot prüft.
- Integration nach Update **neu laden**.
